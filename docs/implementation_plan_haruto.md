# 知能ロボティクス実験の実装方針

作業ブランチは `haruto`。基準は `9c170e8` のB版 `wrs_main_node_b.py`。自宅ではコードの編集、静的確認、ROSを使わないモック検証を行い、シミュレータでの動作と加点は大学で確認する。以下は目標とする動作の設計。

## 全体の流れ

**起動確認 → Task 1で床を片付ける → 机の上を片付ける → Task 2aで障害物を避ける → Task 2bで棚の物体を配達する**

- 開始時にカメラ画像、台車の自己位置、腕と台車の制御が使えることを確認する。観測・制御・移動には個別のタイムアウトを設ける。
- 各工程の結果は、成功・失敗した工程と理由、手の状態（空・保持・不明）、安全な姿勢に復帰できたかを区別して返す。手が空で腕を引けたら探索や次のタスクへ進める。
- 台車は一度に一つの制御元が動かす。`move_base` とその場回転・短距離移動の速度指令を切り替えるときは、前の動作の終了または中止と停止を確認する。
- 地図座標は観測地点や移動先の目安に使う。物体や収納先の位置はRGB-Dで測る。
- 授業版の目安は、Task 1は収納で10点、正規の収納先ならさらに10点。Task 2aは無接触でゴールに到達して30点。Task 2bは正しい物体を届けて30点、違う物体なら20点。

## Task 1　床から机上へ

### 1. 床を確認して、候補を選ぶ

- まず止まった状態で足元と通り道を見る。次に台車全体が通る帯を、進む距離と停止余裕まで含めて確認する。床の物体、壁、家具の脚を避ける。先が見通せない場合は首を振るか、確認済みの範囲で観測位置を変える。
- 床では、安全につかめる物体のうち通路をふさぐ物体を優先する。床を一巡して取れる候補がなくなったら、通れる側から探索側の机へ近づく。机上の探索中も、台車を動かす前に床を確認する。
- 画像から候補に仮の順番を付け、上位からラベル、今回の観測で得た3D位置、手を入れる余裕、使える収納先を確かめる。安全につかめて運びやすい候補から試す。

| 観測の状態 | 対応 |
|---|---|
| 画像や検出サービスが返らない | 台車と首を止めたまま、時間を区切って新しい画像で1回試す。繰り返し失敗した場合は観測系の異常として扱う。 |
| 画像は来たが候補が見えない | 首の角度を変えて再観測する。候補がなければ次の観測地点へ。 |
| 同じ物体のラベルが揺れる | 同じ角度で新しい画像を取り、同じ物体の検出枠を照合する。定まらなければ別の視点か候補へ。 |
| 3D位置が取れない、または怪しい | 同じ角度で新しいRGB画像と対応する深度を取り直す。今回の座標変換が成功し、深度点がまとまっていることを確認する。背景や隣の物体が混ざる場合は別角度で検出枠から取り直し、なお曖昧なら候補を飛ばす。 |

### 2. つかむ

- **床は上から、机の上は横から**手を入れるのを第一候補にする。床・天板・隣の物体に指や手のひらが当たりそうなら、もう一方の方向を検討する。箱は向かい合う平らな側面、ボトルや缶は胴、ボールは床に指が当たらず届く場合に一番太い部分を狙う。薄い物体は両側に指が入る柄などを選ぶ。
- **接近 → 指を閉じる → 支持面から少し持ち上げる → 保持を確認 → 腕を引く**。閉じた直後と持ち上げた後に指先の間隔を見て、見える場合は対象物が手と一緒に動いたかも確かめる。
- 保持が不明なら一度測り直す。それでも不明なら、手を閉じたまま元の支持面まで戻し、物体を預けてから開く。元の場所がふさがっていれば、腕が届く近くの安全な場所を選ぶ。持ち上げ・退避の途中で失敗した場合は、現在の姿勢から安全な復帰経路を引き直す。
- 手が空になって腕を引けたら、同じ物体を新しく観測し、狙う位置か手を入れる方向を変えてもう1回試す。**同じ個体は初回と再試行の計2回**。次に進む前に安全に手を空にする。試行回数はラベルと3D位置で個体ごとに記録し、物体を戻したり落としたりした場合は位置を更新する。

### 3. 収納先を決めて運ぶ

ラベルが決まった時点で本来の収納先を決める。引き出しの開閉は初版の対象外とし、引き出し行きの実際の搬送先は把持前に Bin B と決める。

| 分類 | 本来の収納先 | 初版で最初に向かう先 |
|---|---|---|
| 食品 | Tray A / B | 利用できるトレイ |
| 台所用品 | Container A（大） | Container A |
| 向き指定の物体 | Container B（小） | Container B |
| 工具 | Drawer Top / Bottom | **Bin B** |
| 形状物 | Drawer Left | **Bin B** |
| タスク用品 | Bin A | Bin A |
| 未知物体 | Bin B | Bin B |

1. 把持後に腕を胴体側へ引き、安全に回れることを確かめて収納側へ向き直る。180°は目安。容器・トレイを使う場合は、物体を持ったまま**該当する収納先をその都度観測**する。手で縁が隠れたら首の角度を変え、必要なら台車を止めたまま安全な範囲で腕の高さも変える。遠くて見えなければ既知の観測地点で1回見直す。
2. 台車の停止候補と物体を置く位置を分ける。まず収納先の正面で、机や脚との間隔があり、台車を止めたまま腕が開口まで届いて退避できる点を候補にする。必要なら左右にずらした候補を試す。現行の容器中心から65 cmは候補を作るための参考値。
3. `move_base` で停止候補への経路を計画・実行する。カメラで低い床の物体を確認し、台車と保持物が安全に通れる経路の中から短いものを選ぶ。進路に物体が入ったら中止を確認してから引き直す。
4. 正規の収納先を特定できない、到達できない、開口に空きがない場合は、安全に使える同カテゴリの別候補を優先し、なければ Bin B へ向かう。Bin B に収まれば収納の10点を狙える。Bin B にも安全に運べない、または入る空きがない場合は、腕が届くか安全に到達できる近くの場所に下ろして探索に戻る。搬送中に落とした物体は落下地点を観測し、進路上の障害物として扱う。安全に拾え、試行枠が残っていれば拾い直す。

### 4. 置いて、現在地から次を探す

- 台車を収納先の前に止め、腕を出す前に開口の内側と中の空きを測り直す。物体の幅・向き、手の中での位置ずれ、指を開いて引くための余裕を見て置く位置を選ぶ。
- 物体全体が縁より上にある状態で、置く位置の真上まで動かす。指と腕の退避経路を確保できる範囲で真下に下ろし、落下距離を小さくして離す。開放前に収まらないと分かったら、同じ容器で位置か向きを変えて1回試し、難しければ別の収納先へ切り替える。開放後に失敗した場合は退避を優先する。
- 手が空で腕を引けたら、**収納を終えた現在地から**探索側へ向き直る。見える候補があればそこへ向かい、見えなければ現在地から安全に行ける次の観測地点へ進む。片付けた床は再観測し、床が空いたことを確認してから障害物の記録を更新する。
- 床と机上を一巡し、試せる候補がなくなれば Task 1 を終える。手が空で腕が移動姿勢なら Task 2a へ。現行の14分はコード内の探索打ち切り目安。授業用シミュレータで全体の時間制限がないと確認できたら外す。制限がある場合は、その実測条件に合わせて新規の把持を打ち切る時点を決める。

## Task 2a　壁と床の物体を避ける

1. 開始地点で足元・正面・左右を見て、床を**通れる・物体がある・見えていない**に分ける。床の物体はラベルに関係なく、床上で占める範囲を記録する。
2. 地図上の壁・扉枠・家具と、カメラで見つけた床の物体を重ねてA*で経路を作る。台車全体と余裕が通ることを、経路生成・ショートカット・代替経路のすべてで確かめる。
3. 確認できた区間を短く進み、再観測する。新しい物体が進路に入ったら、現在地から経路を引き直す。前進できない場合は、確認済みの区間を戻るか安全な側へずれ、別の角度から見て別経路を探す。同じ行き止まりの繰り返しを避けるため、試した経路を記録する。
4. **到達と接触の有無を別々に記録**する。2aのゴールに届かなかったり接触したりしても、棚の前まで安全に行ける経路があれば Task 2b を試す。

## Task 2b　棚から取り、人に渡す

1. 棚の前まで行って `/message` の指示文を受け取り、指定された物体と人物を選ぶ。物体名は既存の別名表を使う。人物の判定と固定地点の対応は、Seed 86・25 の実際の指示文を取得して確認する。指示が来なければ棚の前に到達したことを確認し、受信をもう一度試す。
2. 棚は正面から側面を挟むのを基本にする。上の棚板と、少し持ち上げて手前へ抜く経路の空きを確認する。奥に隠れた場合は立ち位置や視点を変えて再観測する。指定物を取れなければ、個体ごとの再試行上限内で狙いを変える。
3. 指定物が見つからない、または取れない場合は、**届け先が確定しているときに限り**別の物体で20点を狙う。指定物を正しく届けられれば30点を狙う。
4. 物体を保持したまま指定の人の前へ移動する。到着、保持、受け渡し姿勢を確認してから開放し、腕を引く。どの位置・高さで実際に加点されるかは大学で確認する。

## 実装順と確認方法

以下は差分と失敗原因を切り分けるための実装順の提案。B版を通し確認の起点にし、班の担当分けと統合手順は [README](../README.md) を参照する。

| 順番 | 実装する範囲 | 確認する結果 |
|---|---|---|
| 1 | 起動確認、工程別の結果とログ、台車制御の切り替え | 画像・座標の取得失敗や移動タイムアウトを区別でき、失敗した動作を終了してから次へ進める。 |
| 2 | Task 1の認識・把持・再試行、床→机上の探索、Bin A/Bへの搬送と収納 | 保持を確認でき、失敗時は安全に手を空にして再試行できる。引き出し行きの物体は Bin B で加点を確認する。 |
| 3 | 容器・トレイの観測、台車の停止位置、正規の収納と代替先 | 保持した物体が視界に入る条件でも対象を見分け、停止位置から腕が届き、開口に収めて加点される。 |
| 4 | Task 2aの床検知と壁・扉枠を含む経路、行き止まりからの復帰 | 低い床の物体と壁を避け、行き止まりで経路を引き直せる。到達と接触の結果をそれぞれ確認できる。 |
| 5 | Task 2bの指示解析、棚からの把持、人への受け渡し | 指示の原文・選んだ物体・人物・画面の得点を照合できる。 |

- **自宅**では、センサから応答がない、古い座標しかない、空振り、1回目の失敗後に再試行、搬送失敗、開放後の退避失敗などをモックで確認する。
- **大学**では、同じ Seed・検出器で変更前の基準を取り、上表の順に区間ごとに確認してから通しで走らせる。Seed 86で基準版と変更版を比較し、その後 Seed 25 でも確認する。
- 毎回、コミット、Seed、検出器、各タスクの実得点、所要時間を記録する。物体ごとのログにはラベル、試行回数、本来の収納先、実際の配置先、失敗工程を残し、**動作完了とシミュレータ上の加点を区別**する。
- 実測で決める値は、床が見える範囲と停止余裕、手が空のときの指先の間隔、収納先ごとの停止距離と開放の余裕、配達時の位置と高さ。授業用シミュレータの全体制限、人物を間違えた場合の配点、`padlock` の授業版での扱いは確認事項。

参考として [授業版の採点と分類](rules_and_strategy.md)、[現行B版](../src/wrs_algorithm21/scripts/wrs_algorithm/algorithm/wrs_main_node_b.py)、[収納先への移動で止まった過去ログ](../run_.log) を参照する。
